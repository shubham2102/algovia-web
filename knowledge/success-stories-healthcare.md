Healthcare success stories:

Everon: Remote Patient-Care Device Re-Architecture — Redesigned nursing-device firmware around BLE, Bluetooth Classic, and GSM/MBIM links with DSP for noise/echo cancellation, extending battery life to about two days and adding multi-patient monitoring.

DiaperID: Parent-Facing App Screening for Liver-Disease Indicators — A React Native app guides parents through image capture; a Python computer-vision model trained on clinically annotated images screens for biliary atresia indicators under an MDR-aware validation workflow.

motus med: Accelerating Infant Seizure Diagnosis with Computer Vision — An AI-driven tool uses smartphone videos taken by parents to enable rapid, accurate detection of infantile spasms, accelerating diagnosis and treatment (MDR Class IIb certification support).

METIS: Point-of-Care Antibiotic Decision Support — Combines clinical recommendation logic with computer-vision analysis of diagnostic inputs in a mobile-compatible, clinician-facing interface for same-visit prescribing guidance.

CaReHigh: Mobile Patient Platform and Registry for FH Care & Research — A React Native app and Python backend support onboarding, adherence tracking, and research participation for familial hypercholesterolemia patients.

Mayo Clinic: Benchmarked Medical-Imaging Pipeline for Stroke Etiology Classification — An end-to-end AI system combining curated image repositories, HistomicsTK preprocessing, and a specialized deep-learning model (PyTorch, MONAI) achieved a Silver Medal benchmark: 46th of 896 teams on Kaggle.
